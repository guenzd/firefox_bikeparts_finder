# Teilefinder 0.7.18

> Archived release description for 0.7.18. Features and validation counts below refer to that release, not the current version. See the [current README](../README.md) and [Firefox distribution guide](UNLISTED.md) for current instructions.

Firefox extension for comparing bicycle parts across BIKE24, Bike-Discount, bike-components and r2-bike.

- Search by product name or confirmed EAN, with variant and maximum-price filters.
- Save a wishlist locally and compare the cheapest available offers.
- Track local price history by EAN and view a price graph.
- Export and import wishlists, results and price history.
- Adding an article to the wishlist immediately searches all four shops.

## Installation

Requires Firefox Desktop 140 or newer. Download the Mozilla-signed `.xpi` attached to this release. In Firefox, open `about:addons`, click the gear icon, choose **Install Add-on From File…**, and select the XPI.

For updates, install the newer signed XPI over the existing extension. Do not uninstall first. Export your data before replacing a temporary development installation.
